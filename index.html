Betriebsstundenzähler ESP32

Betriebsstundenzähler für Seeed Studio XIAO ESP32-C3 direkt aus dem Browser installieren.

  1. XIAO ESP32-C3 per USB anschließen.
  2. Auf Betriebsstundenzähler installieren klicken.
  3. Den seriellen Anschluss des XIAO auswählen.

Betriebsstundenzähler

Version 1.4.3

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge verwenden.

Die vollständige Firmware wird einschließlich Bootloader und Partitionstabelle ab Flash-Adresse 0x0 geschrieben. Vorhandene Einstellungen und gespeicherte Zählerstände werden dabei überschrieben.
